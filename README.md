# Happy Birthday Rumesha 💖

## Add your video
Put your video in this folder and name it exactly `video.mp4`.
- Keep it under ~50 MB so it loads fast on her phone (compress with HandBrake if needed).
- Export as H.264 MP4 so it plays on iPhone and Android.

## Change the letter
Open `index.html` and edit the paragraphs under "My letter to you".

## Deploy on Vercel
Option 1 (easiest): go to vercel.com/new, drag this whole folder in, and click Deploy.
Option 2 (CLI):
    npm i -g vercel
    cd rumesha-birthday
    vercel --prod

Tip: rename the project in Vercel settings (e.g. `happy-birthday-rumesha`) to get a nice link like
https://happy-birthday-rumesha.vercel.app
